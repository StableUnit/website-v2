# Stablecoin Project

This is a React-based stablecoin application built with TypeScript and Vite. The project provides a modern web interface for stablecoin functionality and operations.

## About

This stablecoin project is designed to offer a user-friendly interface for managing stablecoin transactions and operations. Built with React and TypeScript, it leverages Vite for fast development and build processes.

## Technology Stack

- React 18 with TypeScript
- Vite for build tooling and development
- Modern ESLint configuration for code quality

## Getting Started

To run this project locally:

1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Build for production: `npm run build`
